01 — Background on Linux

Where Is Linux Used?

Linux is considerably more lightweight than Windows and powers a huge range of systems you interact with every day — often without knowing it:

  • Websites you visit (most web servers run Linux)
  • Car entertainment and control panels
  • Point of Sale (PoS) systems — checkout tills and registers
  • Critical infrastructure — traffic light controllers, industrial sensors
  • Supercomputers, Android devices, smart appliances

Flavours of Linux

Linux is an umbrella term for multiple operating systems based on UNIX. Thanks to Linux being open-source, variants come in all shapes and sizes — called distributions (distros).

Ubuntu

Most popular desktop/server distro. Extensible — runs as a server or full desktop. Only 512MB RAM needed for Ubuntu Server.

Debian

Stable, widely used base for many other distros including Ubuntu. Known for reliability in server environments.

Kali Linux

Penetration testing focused distro. Comes pre-loaded with security tools. Used in this course for offensive security tasks.

Linux was first released in 1991 by Linus Torvalds.

Key Takeaway

Linux is everywhere. As a security professional, you will encounter Linux systems constantly — on servers, in CTFs, in cloud environments, and on attack boxes. Being comfortable with Linux is non-negotiable.

02 — Running Your First Commands

The Terminal

Linux is often used without a GUI — interaction happens through the terminal. It is purely text-based and intimidating at first, but once you know the commands you become very efficient.

Terminal
tryhackme@linux1:~$ enter commands here

First Two Commands

CommandDescriptionExample
echoOutput any text to the terminalecho "Hello Friend!"
whoamiDisplay the username you are currently logged in aswhoami → tryhackme
echo & whoami

Hello

03 — Interacting With the Filesystem

Navigation Commands

Navigating the filesystem without a GUI is the core Linux skill. These 4 commands cover everything you need to move around and read files.

CommandFull NameWhat It Does
lslistingList files and folders in the current directory
cdchange directoryNavigate into a directory
catconcatenateOutput the contents of a file
pwdprint working directoryShow your current full path location
Filesystem navigation
tryhackme@linux1:~$ ls
Important Files   My Documents   Notes   Pictures
tryhackme@linux1:~$ cd Pictures
tryhackme@linux1:~/Pictures$ ls
dog_picture1.jpg   dog_picture2.jpg   dog_picture3.jpg
tryhackme@linux1:~/Pictures$ pwd
/home/ubuntu/Pictures
tryhackme@linux1:~/Documents$ cat todo.txt
Here's something important for me to do later!

Key Tips

  • ls Pictures — list contents of a directory without navigating into it first
  • cat /home/ubuntu/Documents/todo.txt — use a full path to read a file from anywhere
  • Configuration files (usernames, passwords, configs) are often stored within /etc
Key Takeaway

ls → cd → cat → pwd. These four commands are the building blocks of all Linux navigation. You will use them in every CTF, pentest, and sysadmin task. Memorise them completely.

04 — Searching for Files

find & grep

As you work with Linux systems, manually browsing every directory to find files or data becomes impractical. find and grep automate this.

find — Locate Files by Name

CommandDescriptionExample
find -nameFind a file by exact namefind -name passwords.txt
find -name *.extFind all files with a given extensionfind -name *.txt
Using find
tryhackme@linux1:~$ find -name passwords.txt
./folder1/passwords.txt
tryhackme@linux1:~$ find -name *.txt
./folder1/passwords.txt
./Documents/todo.txt

grep — Search Inside File Contents

grep searches the contents of files for specific values — much more efficient than reading an entire file manually.

Using grep
tryhackme@linux1:~$ wc -l access.log
244 access.log
tryhackme@linux1:~$ grep "81.143.211.90" access.log
81.143.211.90 — [25/Mar/2021:11:17 +0000] "GET /HTTP/1.1" 200 417 "—" "Mozilla/5.0 ..."

Searching Recursively with grep -r

grep recursive
tryhackme@linux1:~$ grep -r "PRETTY_NAME" /etc/
/etc/os-release:PRETTY_NAME="Ubuntu"

The -r flag makes grep search through all files and subdirectories recursively. The output shows the file path before the matching line — making it easy to locate the result.

Key Takeaway

find -name "*.txt" locates files. grep "keyword" file searches inside files. grep -r "keyword" /path/ searches across all files recursively. These three patterns cover 90% of real-world file searching tasks.

05 — Shell Operators

Powering Up Commands

Shell operators let you chain commands, redirect output, and run tasks in the background — turning simple commands into powerful workflows.

OperatorDescriptionExample
& Run a command in the background. Frees the terminal while the command executes. cp large_file.zip /backup &
&& Run a second command only if the first succeeds. Chain dependent commands. command1 && command2
> Redirect output to a file. Overwrites existing content. echo hey > welcome
>> Append output to a file. Does not overwrite — adds to the end. echo hello >> welcome
Shell operators in action
tryhackme@linux1:~$ echo hey > welcome
tryhackme@linux1:~$ cat welcome
hey
tryhackme@linux1:~$ echo hello >> welcome
tryhackme@linux1:~$ cat welcome
hey
hello
Key Takeaway

> overwrites, >> appends. && chains commands conditionally (second only runs if first succeeds). & backgrounds a process. These operators are fundamental to shell scripting and automation.

Vocabulary

Key Terms & Commands

  • Terminal — The text-based interface for interacting with a Linux system. Also called shell, command line, or CLI.
  • Distribution (distro) — A variant of Linux. Examples: Ubuntu, Debian, Kali, Arch, CentOS.
  • echo — Output text to the terminal. echo "Hello"
  • whoami — Display the current logged-in username.
  • ls — List files and directories in the current location.
  • cd — Change directory. cd Documents / cd .. (go up one level)
  • cat — Output the contents of a file to the terminal. cat file.txt
  • pwd — Print Working Directory — shows your current full path.
  • find — Locate files by name or extension. find -name "*.txt"
  • grep — Search inside file contents for a string. grep "keyword" file.txt
  • grep -r — Recursive grep — searches all files and subdirectories.
  • wc -l — Word count lines — counts the number of lines in a file.
  • & — Background operator. Run command without blocking the terminal.
  • && — AND operator. Run second command only if first succeeded.
  • > — Output redirect (overwrite). Sends command output to a file.
  • >> — Output redirect (append). Adds output to end of existing file.
  • /etc — Linux directory containing configuration files, often including passwords and system settings.

Self-Check

Click on an answer to reveal it. Try to answer from memory first!

What year was Linux first released?
1991, by Linus Torvalds.
What command outputs text to the terminal? What command shows the current user?
echo "text" outputs text. whoami shows the current logged-in username.
What command lists files in the current directory?
ls (listing). You can also use ls <directory> to list a specific directory without navigating into it.
What command changes your current directory?
cd (change directory). Example: cd Documents. Use cd .. to go up one level.
What does cat do? What does pwd do?
cat outputs the contents of a file to the terminal. pwd (print working directory) shows your current full path.
How do you find a file named "passwords.txt" anywhere on the system?
find -name passwords.txt — searches from the current directory downward for a file with that exact name.
How do you find all .txt files on the system?
find -name "*.txt" — the asterisk (*) is a wildcard that matches any filename with a .txt extension.
What does grep do? Give an example.
grep searches inside file contents for a specific string. Example: grep "81.143.211.90" access.log returns only lines containing that IP address.
What does grep -r do?
Searches recursively — checks every file in the current directory and all subdirectories for the search string. Example: grep -r "PRETTY_NAME" /etc/
What is the difference between > and >> operators?
> redirects output to a file and OVERWRITES existing content. >> redirects output and APPENDS to the end of the file without overwriting.
What does the && operator do?
Chains two commands — the second command only runs if the first succeeds. Example: command1 && command2
What does the & operator do?
Runs a command in the background, freeing the terminal for other commands while the task continues executing.
If you want to output "TryHackMe" to the terminal, what is the command?
echo TryHackMe (no quotes needed for a single word with no spaces).
If you want to replace the contents of a file named "passwords" with "password123", what is the command?
echo password123 > passwords — the > operator overwrites the file with the new content.
What Linux directory often contains configuration files and system settings?
/etc — it stores system-wide configuration files. Often targeted during enumeration for credentials and config details.
