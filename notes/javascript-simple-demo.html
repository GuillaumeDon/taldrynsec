01 — Introduction

JavaScript: Client-Side and Server-Side

JavaScript was initially designed to run inside web browsers to make pages interactive. With Node.js, it became a server-side language too — you can now run JS from the command line just like Python.

This room rebuilds the exact same "Guess the Number" game from the Python room, using JavaScript. The goal is to highlight language differences while the logic stays identical.

We run JS with Node.js: node guess_v3.js

Key Takeaway

JavaScript = the language of the web browser. Node.js = JavaScript on the server/terminal. Same language, different runtime. Run JS files from the terminal with node filename.js.

02 — Variables & Constants

let vs const

JavaScript has two ways to declare storage. Unlike Python (where you just write x = 5), JS requires an explicit keyword.

  • let — declares a variable: its value can change during the program. Used for tries and guess.
  • const — declares a constant: its value is set once and never changes. Used for secret.
let tries = 0; let guess = 0; // start outside valid range (secret is 1..20) const secret = Math.floor(Math.random() * 20) + 1; // 1 <= secret <= 20

How Math.random() works

  • Math.random() → random decimal between 0 (inclusive) and 1 (exclusive). Example: 0.572
  • * 20 → stretches range to 0–20. Example: 11.44
  • Math.floor() → rounds down to integer. Example: 11
  • + 1 → shifts range from 0–19 to 1–20

Displaying output

Python uses print(). JavaScript uses console.log().

console.log("I'm thinking of a number between 1 and 20");
Key Takeaway

Use let for values that change, const for values that are fixed. JS statements end with a semicolon ; (optional but conventional). Output = console.log(), not print().

03 — Prompting the User for Input

readline + parseInt

Reading terminal input in JS is more involved than Python's input(). We use Node.js's built-in readline module, which handles input/output streams asynchronously.

import * as readline from "node:readline/promises"; import { stdin as input, stdout as output } from "node:process"; const rl = readline.createInterface({ input, output }); // Inside async context: const text = await rl.question("Take a guess: "); // returns a string guess = parseInt(text, 10); // convert string → integer (base 10)

Key differences from Python

  • Python: text = input("prompt") — one line, synchronous
  • JavaScript: needs readline module + await rl.question()
  • Conversion: Python uses int(text) — JS uses parseInt(text, 10)
  • The 10 in parseInt specifies base-10 (decimal). Always include it to avoid edge cases.
Key Takeaway

rl.question() returns a string, just like Python's input(). Convert with parseInt(text, 10) before any numeric comparison. The await keyword pauses execution until the user has typed their answer.

04 — Conditional Statements

if / else if / else

The logic is identical to Python. The syntax differs: JS uses curly braces { } to delimit blocks (not indentation), and writes else if instead of elif. Also, the OR operator is || in JS (vs or in Python).

if
(guess < 1 || guess > 20) → "That number is out of range. Try again."
else if
(guess < secret) → "Too low, try again."
else if
(guess > secret) → "Too high, try again."
else
→ "You got it in [tries] tries!" (guess === secret)
if (guess < 1 || guess > 20) { console.log("That number is out of range. Try again."); } else if (guess < secret) { console.log("Too low, try again."); } else if (guess > secret) { console.log("Too high, try again."); } else { console.log("You got it in", tries, "tries!"); }
Key Takeaway

Python uses elif + indentation. JavaScript uses else if + { } braces. OR is || in JS, or in Python. The logic is identical — only syntax changes.

"Not equal" in JS is !==. The try/finally block ensures rl.close() always runs to cleanly release the input stream. Same loop logic as Python's while guess != secret: — only the syntax differs.

Vocabulary

Key Terms

  • Node.js — JavaScript runtime that lets you run JS outside the browser, directly in the terminal.
  • let — JS keyword to declare a variable (value can change).
  • const — JS keyword to declare a constant (value cannot be reassigned).
  • console.log() — JS equivalent of Python's print(). Outputs to the terminal.
  • readline — Node.js built-in module for reading terminal input line by line.
  • rl.question() — Displays a prompt and waits for the user to type a line. Returns a string.
  • parseInt(text, 10) — Converts a string to an integer in base 10. JS equivalent of Python's int().
  • Math.random() — Returns a random float between 0 (inclusive) and 1 (exclusive).
  • Math.floor() — Rounds a number down to the nearest integer.
  • await — Pauses execution until an asynchronous operation completes (e.g. waiting for user input).
  • || (OR) — Logical OR operator in JavaScript. True if at least one operand is true.
  • !== (strict not equal) — Returns true if values differ. Preferred over != in modern JS.
  • try / finally — Ensures code in the finally block always runs, even if an error occurs.
  • Semicolon ; — Marks the end of a JS statement. Optional in modern JS but conventional.

What is the difference between let and const in JavaScript?
let declares a variable whose value can change. const declares a constant whose value is set once and cannot be reassigned.
What word is used to declare a variable in JavaScript?
let. Example: let tries = 0;
What word is used to declare a constant in JavaScript?
const. Example: const secret = 12;
What is the JS equivalent of Python's print()?
console.log(). Example: console.log("Hello!");
What method converts user input to a number in JavaScript?
parseInt(text, 10). The second argument (10) specifies base-10 (decimal).
How does Math.floor(Math.random() * 20) + 1 produce a number between 1 and 20?
Math.random() gives 0–0.999…, ×20 gives 0–19.99…, Math.floor() rounds to 0–19, +1 shifts to 1–20.
How does JavaScript write "else if"? How does Python write it?
JavaScript: else if. Python: elif.
How is the OR operator written in JavaScript? In Python?
JavaScript: || (double pipe). Python: or (keyword).
How is "not equal" written in JavaScript?
!== (strict not equal). Also !== is preferred over != in modern JS.
How does JS delimit code blocks (if body, while body)? How does Python do it?
JavaScript uses curly braces { }. Python uses indentation (whitespace).
What does await do in JavaScript?
It pauses execution of the current async function until the awaited promise resolves — e.g. waiting for the user to type input.
What is the purpose of rl.close() in the finally block?
It releases the readline interface and closes the input stream. Without it, the Node.js process may hang after the game ends.
What command runs a JavaScript file with Node.js?
node filename.js. Example: node guess_v3.js
What will the program display if secret is 10 and the user guesses 35?
"That number is out of range. Try again." — because 35 > 20, the first if condition (guess > 20) is true.
