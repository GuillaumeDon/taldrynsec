01 — Opening the Door

Introduction to Port Forwarding

Port forwarding is an essential component in connecting applications and services to the Internet. Without it, applications and services such as web servers are only available to devices within the same direct network (this is known as an intranet).

How It Works

A server with IP 192.168.1.10 runs a webserver on port 80. Without port forwarding, only the two other computers on this network can access it. With port forwarding configured on the router, Network #2 can access the webserver using the public IP address of Network #1 (e.g. 82.62.51.70).

Port Forwarding vs Firewall

Easy to confuse but very different: port forwarding opens specific ports (tells the router where to send incoming packets). Firewalls determine if traffic can travel across those ports (even if they're open by port forwarding).

Key Takeaway

Port forwarding is configured at the router. It maps a public port to an internal IP + port, making internal services accessible from the Internet. Without it, your services stay trapped on the intranet.

02 — The Border Guard

Firewalls 101

A firewall is a device within a network responsible for determining what traffic is allowed to enter and exit. Think of it as border security for a network. An administrator configures a firewall to permit or deny traffic based on:

  • Where the traffic is coming from? (source network/IP)
  • Where is the traffic going to? (destination network/IP)
  • What port is the traffic for?
  • What protocol is the traffic using? (UDP, TCP, or both?)

Firewalls perform packet inspection to determine the answers. They come in all shapes and sizes — from dedicated hardware in large networks to software like Snort on residential routers. They operate at Layers 3 & 4 of the OSI model.

Stateful vs Stateless Firewalls

Stateful
Uses the entire information from a connection — not just individual packets, but the behaviour of the whole connection. Dynamic decision making. Resource-intensive. Example: a firewall could allow the first parts of a TCP handshake but block if it would later fail. If a connection from a host is bad, it blocks the entire device.
Stateless
Uses a static set of rules to determine if individual packets are acceptable. A bad packet from a device won't necessarily block the entire device. Uses much fewer resources but is "dumber" — only effective for the rules defined within them. Great against DDoS attacks (large amounts of traffic from many hosts).
Key Takeaway

Stateful = inspects the entire connection (smarter, heavier). Stateless = inspects individual packets against static rules (faster, simpler). Both operate at OSI Layers 3 & 4.

03 — Secure Tunnels

VPN Basics

A Virtual Private Network (VPN) allows devices on separate networks to communicate securely by creating a dedicated path between each other over the Internet (known as a tunnel). Devices connected within this tunnel form their own private network.

VPN Benefits

Connect Remote Networks
A business with multiple offices can connect them. Resources like servers and infrastructure can be accessed from another office.
Privacy
VPN uses encryption to protect data. Only understood between the devices it was being sent from and to. Useful on public WiFi where no encryption is provided by the network.
Anonymity
Journalists and activists use VPNs in countries where freedom of speech is controlled. Your traffic is normally viewable by your ISP and can be tracked. Note: a VPN that logs all your data/history is essentially the same as not using a VPN.

VPN Technologies

  • PPP — Used by PPTP to allow authentication and provide encryption. Uses a private key & public certificate to match. Technology is not capable of leaving a network by itself (non-routable).
  • PPTP (Point-to-Point Tunneling Protocol) — The technology that allows data from PPP to travel and leave a network. Very easy to set up and supported by most devices. However, weakly encrypted compared to alternatives.
  • IPSec (Internet Protocol Security) — Encrypts data using the existing IP framework. Difficult to set up but boasts strong encryption and is supported on many devices.
Key Takeaway

VPN = encrypted tunnel over the Internet. PPP = only encrypts, can't leave the network. PPTP = easy but weak encryption. IPSec = hard to set up but strong encryption. Always check if your VPN provider logs your data — if they do, it defeats the purpose.

04 — The Network Hardware

LAN Networking Devices

What is a Router?

A router's job is to connect networks and pass data between them using routing (hence the name). Routers operate at Layer 3 of the OSI model. They often feature an interactive interface (website or console) for administrators to configure rules like port forwarding or firewalling.

Routing is useful when devices are connected by many paths — the most optimal path is chosen based on: shortest path, most reliable path, and fastest physical medium (copper vs fibre).

Routers are dedicated devices and do not perform the same functions as switches.

What is a Switch?

A switch is a dedicated networking device responsible for providing a means of connecting multiple devices (from 3 to 63) using Ethernet cables.

Layer 2 Switch vs Layer 3 Switch

Layer 2 Switch
Forwards frames (remember: frames have MAC addresses, not IP) to the connected devices using their MAC address. Solely responsible for sending frames to the correct device. Cannot operate at Layer 3 (no IP routing).
Layer 3 Switch
More sophisticated. Can perform some responsibilities of a router: send frames to devices (like Layer 2) AND route packets to other devices using the IP protocol.

VLANs (Virtual Local Area Network)

A technology called VLAN allows specific devices within a network to be virtually split up. This split means they can all benefit from the same Internet connection but are treated separately. This network separation provides security because it means that rules determine how specific devices communicate with each other.

Example: a Layer 3 switch with two VLANs — Sales Department (VLAN 1, 192.168.1.1) and Accounting Department (VLAN 2, 192.168.2.1). Both can access the Internet, but cannot communicate with each other even though they're connected to the same switch.

Key Takeaway

Router = connects networks (Layer 3). Switch = connects devices within a network. Layer 2 switch = uses MAC addresses only. Layer 3 switch = uses MAC + IP (can do some routing). VLAN = virtual separation on the same physical switch for security.

Vocabulary

Key Terms

  • Port Forwarding — Configuring the router to direct incoming traffic on a specific port to an internal device.
  • Intranet — A private network accessible only to devices within the same direct network.
  • Firewall — Device that permits or denies traffic based on rules (source, destination, port, protocol).
  • Packet Inspection — Examining packets to decide if they should be allowed or blocked.
  • Stateful Firewall — Inspects entire connection behaviour. Smarter, more resource-intensive.
  • Stateless Firewall — Inspects individual packets against static rules. Faster, less resource-intensive.
  • DDoS — Distributed Denial-of-Service. Attack using large amounts of traffic from many hosts.
  • VPN — Virtual Private Network. Encrypted tunnel over the Internet between devices.
  • Tunnel — The dedicated encrypted path created by a VPN.
  • PPP — Point-to-Point Protocol. Provides authentication and encryption. Non-routable alone.
  • PPTP — Point-to-Point Tunneling Protocol. Easy to set up, weak encryption.
  • IPSec — Internet Protocol Security. Strong encryption, harder to set up.
  • Router — Connects different networks. Operates at Layer 3. Performs routing.
  • Routing — Finding the best path for data to travel between networks.
  • Switch — Connects multiple devices within a network using Ethernet cables.
  • Layer 2 Switch — Forwards frames using MAC addresses only.
  • Layer 3 Switch — Forwards frames (MAC) AND routes packets (IP). Can do some router work.
  • VLAN — Virtual Local Area Network. Virtually splits devices on the same switch for security and isolation.
  • Snort — Open-source software firewall / intrusion detection system.
