01 — What Is Offensive Security?

The Attacker's Perspective

Offensive Security proactively tests systems by attempting to break into them — with the goal of finding weaknesses before real attackers do. Rather than waiting for attackers to strike, offensive security professionals test systems to find and fix weaknesses first.

In this room, "hacking" refers to penetration testing: an ethical, legal, and structured method for identifying weaknesses within a defined scope so they can be addressed.

A hacker starts with three questions:

  • What is exposed?
  • What can be accessed?
  • What assumptions does the system make?

These are applied methodically, observing how systems respond to unexpected input.

Key Takeaway

Offensive security = find it before the attacker does. Ethical hackers are explicitly authorised to test systems in a controlled, legal manner. The purpose is to improve security, not to cause damage.

02 — Finding Weaknesses

Core Offensive Security Terms

Red Teaming

A structured attack methodology simulating a real adversary to test the effectiveness of defences and find vulnerabilities within a defined scope.

Penetration Test

A structured security assessment where an authorised tester attempts to identify and exploit vulnerabilities within a defined scope to understand real-world risk.

Vulnerability

A weakness or flaw in a system, application, or configuration that an attacker could abuse.

Exploit

A technique or method used to take advantage of a vulnerability — e.g. accessing restricted functionality or data.

Enumeration

Collecting details about a system, users, and services to find weak points. The core recon activity before exploiting anything.

Scope

The boundaries of what is allowed to be tested during an engagement. Defines which systems, applications, and actions are permitted — and what is off-limits.

Hands-On: GoBuster — Directory Enumeration

Before exploiting anything, you need to map the target. Hidden pages (not linked from the main site) can expose admin panels, backup files, or test pages. GoBuster automates this by trying thousands of common directory and file names from a wordlist.

Manual first — check sitemap

Always start by checking http://target.com/sitemap manually. Then use automation for the rest.

GoBuster command

user@thm:~$ gobuster dir --url http://www.onlineshop.thm/ -w /usr/share/wordlists/dirbuster/directory-list.txt

Command breakdown

gobusterThe CLI tool for web content discovery
dirSpecifies directory and file enumeration mode
--url <target>Sets the target website GoBuster will scan
-w <wordlist>The wordlist GoBuster uses to guess directory and file names

GoBuster tries each word in the list as a URL path. If the server returns anything other than 404, the page exists. A 200 OK means it's accessible. This reveals hidden pages the developers never linked publicly.

Key Takeaway

Enumeration comes before exploitation. GoBuster is a directory brute-forcer — it systematically tries wordlist entries as URL paths to find hidden pages. A page existing without being linked is not "hidden" — it's just undiscovered until someone looks.

03 — Exploiting Weaknesses

Chaining Weaknesses + The Hacker Mindset

A single weakness may not seem critical on its own — but weaknesses chain together. Think of dominos: one falling on its own doesn't cause much damage. But when they're placed close together, knocking over just one can trigger a reaction that brings them all down.

Example from this room: a hidden /login page (discovered via GoBuster) combines with weak passwords to give full admin access to the application.

Think Like a Hacker

Ask questions

Don't assume a feature works as intended. Ask "What if it doesn't?"

Test the unexpected

Try actions and inputs that the developers didn't consider.

Chain small weaknesses

A tiny flaw may be harmless alone, but could be the first domino of a bigger impact.

Think like an adversary

Ask: "How would a malicious actor approach this target?"

A Valuable Target: What Attackers Want

Once access is gained to a private area of an application, attackers can reach:

  • Sensitive functionality — Actions like modifying data, triggering processes only available to authorised users.
  • User data — Names, emails, account details, personal info.
  • Administrative features — Manage users, change settings, gain full control.
  • Further attack opportunities — Pivot to other systems, escalate privileges.

Hands-On: Hydra — Dictionary Attack

After finding a hidden /login page, the next step is testing whether weak credentials exist. Hydra automates login attempts using a wordlist — this is a dictionary attack.

user@thm:~$ hydra -l admin -P passlist.txt www.onlineshop.thm http-post-form "/login:username=^USER^&password=^PASS^:F=incorrect" -V

Command breakdown

hydraPassword cracking / login brute-force tool
-l adminSet the username to try: admin
-P passlist.txtWordlist of passwords to try
www.onlineshop.thmTarget website
http-post-formIndicates this is an HTTP POST login form
"/login:...:F=incorrect"How the login request is built and how Hydra detects failure (response contains "incorrect")
-VVerbose — shows each attempt in real time

The Attack Chain — Dominos in Action

1Recon: Navigate to the target website, check sitemap manually
2Enumeration: Run GoBuster to discover hidden pages → finds /login
3Vulnerability: Hidden login page + weak password policy
4Exploit: Run Hydra dictionary attack → cracks admin password
5Impact: Full admin access to the web application
Key Takeaway

Hydra = automated login brute-forcer. Dictionary attack = trying a known list of passwords. One hidden page + one weak password = full compromise. This is why defence-in-depth matters — no single control should be the only barrier.

Vocabulary

Key Terms

  • Offensive Security — Proactively testing systems by attempting to break into them to find weaknesses before real attackers do.
  • Penetration Testing — An ethical, legal, authorised security assessment where a tester attempts to identify and exploit vulnerabilities within a defined scope.
  • Red Teaming — A structured attack simulation mimicking real adversaries to test an organisation's defences end-to-end.
  • Vulnerability — A weakness or flaw in a system, application, or configuration that an attacker could exploit.
  • Exploit — A method or technique used to take advantage of a vulnerability to achieve an unintended outcome.
  • Enumeration — Systematically collecting information about a target (directories, users, services, ports) to identify attack surface.
  • Scope — The defined boundaries of what is allowed during a security engagement. Going outside scope = unauthorised access.
  • Credentials — Login details — a username and password combination that unlocks access.
  • Authentication — The process of verifying identity when logging in.
  • Dictionary Attack — Trying a predefined wordlist of likely passwords against a login form until one succeeds.
  • Brute-Force Attack — Trying all possible combinations systematically. Dictionary attacks are a focused form of brute-force.
  • GoBuster — A CLI tool for directory and file enumeration on web servers using a wordlist.
  • Hydra — A fast, flexible password cracking tool that automates login attempts against many protocols and form types.
  • Wordlist — A file containing a list of common passwords, usernames, or directory names used by enumeration and brute-force tools.
  • Domino Effect (chaining) — The principle that small individual weaknesses, when combined, can lead to a significant security breach.

What is the difference between a vulnerability and an exploit?
A vulnerability is the weakness. An exploit is the technique used to take advantage of that weakness.
What is enumeration?
Systematically collecting details about a target (directories, services, users) to identify weak points before attempting to exploit anything.
What is scope in a penetration test?
The exact systems and actions allowed during the engagement. Defines what is permitted and what is off-limits. Going outside scope is unauthorised access.
What does GoBuster do? What is its main use?
It discovers hidden directories and files on web servers by trying words from a wordlist as URL paths. Used during enumeration to find pages not linked from the main site.
What does the -w flag mean in a GoBuster command?
It specifies the wordlist file GoBuster uses to guess directory and file names.
What HTTP status code indicates a page was successfully found by GoBuster?
200 OK — the page exists and is accessible. GoBuster flags any response that is not 404 (Not Found).
What is a dictionary attack?
Trying a predefined wordlist of common passwords against a login system until one succeeds. Faster than full brute-force because it focuses on likely passwords.
What does Hydra do? What does the -l flag mean?
Hydra automates login attempts (dictionary / brute-force attack). The -l flag sets a single username to test (lowercase = single, uppercase -L = usernames from a file).
What does F=incorrect mean in a Hydra http-post-form command?
It tells Hydra how to detect a failed login — if the response contains the word "incorrect", that attempt failed. When this string is absent, Hydra knows the login succeeded.
Why is chaining weaknesses dangerous?
A single weakness may be low-risk alone. But combined with other weaknesses, it creates a chain reaction — like dominos. A hidden page + a weak password = full admin compromise.
