01 — The Basics

What is Networking?

Networks are simply things connected. Your friendship circle is a network — people connected by shared interests. In computing, networking is the same idea applied to technological devices.

Networks in Everyday Life

  • A city's public transportation system
  • The national power grid for electricity
  • Postal systems for sending letters and parcels

In computing, a network can be formed by anywhere from 2 devices to billions. These devices include everything from laptops and phones to security cameras, traffic lights, and even farming equipment.

Key Takeaway

A network is the key term for devices connected together. Networks are so embedded in modern life that understanding them is essential for cybersecurity. They come in all shapes and sizes.

02 — The Big Network

What is the Internet?

The Internet is one giant network made up of many, many small networks within itself. Think of it as networks of networks all connected together.

Brief History

  • Late 1960s — ARPANET — The first iteration of the Internet. A project funded by the United States Defence Department and was the first documented network in action.
  • 1989 — World Wide Web (WWW) — Invented by Tim Berners-Lee. This is when the Internet started being used as a repository for storing and sharing information, just like it is today.

Private vs Public Networks

  • Private network — A small network (e.g. your home, your company). Devices communicate internally.
  • Public network — Networks connecting private networks together = the Internet.
Key Takeaway

The Internet is made up of many small private networks all joined together. The networks connecting those private networks are called public networks — or the Internet. Devices use labels to identify themselves on a network.

03 — Identification

Identifying Devices on a Network

To communicate and maintain order, devices must be both identifying and identifiable on a network. Devices are similar to humans: we have fingerprints and names. Devices have two ways of being identified:

IP Address

An IP address (Internet Protocol address) can be used to identify a host on a network for a period of time. It's a set of numbers divided into four octets.

  • Example: 192.168.1.1
  • Each octet ranges from 0-255
  • IP addresses can change from device to device (like changing your name) but are still an identity behind it
  • Devices can be on both a private and public network — depending on where, they have a public or private IP address

Public IP addresses identify the device on the Internet, while private addresses identify devices amongst other local devices. Two devices on the same private network will share the same public IP address.

Public IP addresses are given by your Internet Service Provider (ISP) at a monthly cost.

IPv4 vs IPv6

  • IPv4 — Current main addressing scheme. Uses a numbering system of 2^32 IP addresses (~4.29 billion). We're running out!
  • IPv6 — New iteration. Supports up to 2^128 addresses (340 trillion+). More efficient, resolves issues with IPv4.

MAC Address

A MAC address (Media Access Control) is a twelve-character hexadecimal number unique to each device's physical network interface. It is set by the manufacturer and burned into the hardware — think of it like a serial number.

  • Example: a4:c3:f0:85:ac:2d
  • First 6 characters = vendor who made the network interface (e.g. Intel)
  • Last 6 characters = unique address of that specific interface
  • MAC addresses can be faked/spoofed — a process called spoofing

Spoofing occurs when a networked device pretends to identify as another by using its MAC address. This can break poorly implemented security designs that assume devices are trustworthy based on MAC address alone. If a device is pretending to "spoof" its MAC address, a firewall would incorrectly think it's receiving communication from the authorized device.

Key Takeaway

IP address = logical address, can change, identifies a device on a network for a period of time. MAC address = physical address, burned into hardware, permanent (but can be spoofed). Both are needed to identify devices on a network.

04 — First Tool

Ping (ICMP)

Ping is one of the most fundamental network tools. It uses ICMP (Internet Control Message Protocol) packets to determine the performance of a connection between devices — for example, if the connection exists or is reliable.

How Ping Works

  • Ping sends an ICMP echo packet to the target device
  • The target responds with an ICMP echo reply
  • The time taken for this round trip is measured (in milliseconds)

Syntax

  • ping <IP address or website URL>
  • Example: ping 192.168.1.254
  • Example: ping 8.8.8.8 (Google's DNS)

Ping is available on both Linux and Windows. It can be performed against devices on your home network or resources like websites.

Reading Ping Output

  • Bytes sent — Size of the ICMP packet (usually 56 or 64 bytes)
  • icmp_seq — Sequence number of the packet
  • ttl — Time to live (how many hops before the packet expires)
  • time — Round trip time in milliseconds (lower = better)
  • packet loss — 0% means all packets received (connection is reliable)
Key Takeaway

Ping uses ICMP (not TCP or UDP). It's the simplest way to check if a device is reachable and how fast the connection is. Syntax: ping <target>. It's the first tool you'll use in any network troubleshooting scenario.

Vocabulary

Key Terms

  • Network — Devices connected together.
  • Internet — A giant network made up of many small networks connected together.
  • ARPANET — The first documented network (late 1960s, US Defence Department).
  • World Wide Web (WWW) — Invented by Tim Berners-Lee in 1989.
  • Private Network — A local network (home, company).
  • Public Network — Networks connecting private networks = the Internet.
  • IP Address — Internet Protocol address. Logical address to identify a device on a network. Can change.
  • IPv4 — 4 octets (0-255), ~4.29 billion addresses. Running out.
  • IPv6 — 128-bit addresses, 340 trillion+ addresses. The future.
  • ISP — Internet Service Provider. Assigns your public IP address.
  • MAC Address — Media Access Control. 12-character hex number burned into hardware. Physical and (theoretically) permanent.
  • Spoofing — Faking a MAC address to impersonate another device.
  • Ping — Tool to test connectivity between devices.
  • ICMP — Internet Control Message Protocol. Protocol used by ping.
  • TTL — Time to Live. Number of hops before a packet expires.
