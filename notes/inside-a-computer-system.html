02 — The Building Blocks

Inside a Computer System

Nearly every computer system includes the same building blocks. Each part has its own job, and together they make the computer work. The room uses a human body analogy to explain each component.

CPU
The Brains. The Central Processing Unit executes instructions and does the thinking. Every operation passes through it.
Motherboard
The Skeleton and Nerves. Connects all components together and allows them to communicate. Everything plugs into it.
RAM
Short-term Memory. Random Access Memory holds data the CPU is actively using. Fast but temporary — loses data when powered off.
HDD / SSD
Long-term Memory. Hard Disk Drive / Solid State Drive store files, programs, and the operating system. Keep data when powered off.
GPU
Visual Cortex. The Graphics Processing Unit handles rendering images, video, and 3D graphics. Critical for gaming and AI.
PSU
Heart and Lungs. The Power Supply Unit delivers electricity to all components. Without it, nothing runs.
Key Takeaway

Memorize the analogy — it makes each component easy to remember. CPU = brain, RAM = short-term memory, HDD/SSD = long-term memory, Motherboard = skeleton, GPU = visual cortex, PSU = heart & lungs.

Step 1 — Press the Power Button

When you press the power button, a signal is sent to the PSU to allow power to flow. Like the body receiving oxygen when we wake up.

Step 2 — Firmware Starts

Core components are up and running, but the "brain" isn't yet conscious. A computer contains firmware that allows its components to start up. The central system managing this is the UEFI (Unified Extensible Firmware Interface).

  • UEFI — Modern firmware interface.
  • BIOS — Basic Input/Output System. Old term still mentioned, but mostly replaced by UEFI. Does the same job.

Step 3 — POST (Power-On Self Test)

UEFI runs the POST: a test that every required component is present, configured correctly, and functioning. If something is wrong, alarm signals (beeps) are triggered. Like the body checking if everything works before getting out of bed.

Step 4 — Select Boot Device

The system searches for the boot routine location. The UEFI holds an ordered list prioritizing which device to look at first for the boot routine for the Operating System.

Step 5 — Initiate Bootloader

On the selected boot device, the bootloader is initiated. The bootloader transfers the Operating System from the boot device to the RAM. Once the OS is loaded, the UEFI hands control over to the OS.

Key Takeaway

The boot process is a security-critical phase often targeted by hackers (bootkits, rootkits). Understanding it is essential for defense. Remember the order: Power → Firmware (UEFI) → POST → Boot Device → Bootloader → OS.

04 — Conclusion

Why It All Matters

We've covered the core components of a computer system and how it boots up. When learning cybersecurity concepts later on, you'll often need to recall the function of each component and how they interact.

The boot process is a very important concept — it's sometimes targeted by hackers (e.g. UEFI/BIOS rootkits, bootkit malware, Evil Maid attacks). Next room: Computer Types — different combinations and specializations of these components create diverse computer systems.

Vocabulary

Key Terms

  • CPU — Central Processing Unit. The brain of the computer.
  • Motherboard — The board connecting all components together.
  • RAM — Random Access Memory. Fast, volatile, short-term memory.
  • HDD — Hard Disk Drive. Long-term storage using spinning platters.
  • SSD — Solid State Drive. Long-term storage using flash memory (faster than HDD).
  • GPU — Graphics Processing Unit. Handles visual rendering.
  • PSU — Power Supply Unit. Delivers electricity to components.
  • Firmware — Low-level software that lets hardware components start up.
  • UEFI — Unified Extensible Firmware Interface. Modern firmware managing the boot process.
  • BIOS — Basic Input/Output System. Older term, largely replaced by UEFI.
  • POST — Power-On Self Test. Verifies all components are working at boot.
  • Bootloader — Small program that loads the OS from the boot device into RAM.
  • OS — Operating System. Software that manages the computer (Windows, Linux, macOS).
  • Boot Device — The storage device containing the OS (usually SSD or HDD).
