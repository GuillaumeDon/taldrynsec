01 — Why OS Security Matters

Introduction to Operating System Security

Every day you interact directly or indirectly with an operating system. Your smartphone might be running Android or iOS, and you might have plenty of private data on it: private conversations, photos, email, passwords, banking apps.

The same goes for your laptop or computer. Confidential work files, personal documents, saved passwords, photos — the list of sensitive data goes on. You want to ensure that your data is secure.

The CIA Triad

When we talk about security, we should think of protecting three things:

Confidentiality

Ensure that secret and private files and information are only available to intended persons.

Integrity

It is crucial that no one can tamper with the files stored on your system or while being transferred on the network.

Availability

You want your laptop or smartphone to be available to use anytime you decide to use it.

Key Takeaway

The CIA triad is the foundation of all cybersecurity. Every attack targets one or more of these pillars. Every defense protects one or more. Memorize it: Confidentiality (who can see it?), Integrity (has it been changed?), Availability (can I use it?).

02 — Three Weaknesses

Common Examples of OS Security

Security is concerned with attacks against: Confidentiality, Integrity, and Availability. This room focuses on three common weaknesses targeted by malicious users:

1. Authentication and Weak Passwords

Authentication is the act of verifying your identity, be it a local or a remote system. It can be achieved via three main ways:

  • Something you know — A password or a PIN code.
  • Something you are — A fingerprint.
  • Something you have — A phone number via which you can receive an SMS message.

Since passwords are the most common form of authentication, they are also the most attacked. Many users tend to use easy-to-guess passwords or the same password on many websites. Attackers are well aware of this tendency.

Top 20 Most Common Passwords

The National Cyber Security Centre (NCSC) published the 100,000 most common passwords. The top ones include: 123456, 123456789, qwerty, password, 111111, abc123, password1, 12345, monkey, dragon.

Words not in the dictionary like qwertyuiop and 1q2w3e4r5t seem complex but are very predictable — they just follow the keyboard layout.

Key Takeaway

If an attacker can guess your password for any online account, they can access your private data. Use complex passwords and different passwords for different accounts. A password manager is your best friend.

2. Weak File Permissions

Proper security dictates the principle of least privilege: in a work environment, you want any file accessible only by those who need to access it to get work done. In simpler terms: "who can access what?"

Weak file permissions make it easy for the adversary to attack confidentiality and integrity. They can access files they should not be able to access, and they can modify files that they should not be able to edit.

3. Access to Malicious Programs

Depending on the type of malicious program, it can attack confidentiality, integrity, and availability:

  • Trojan Horses — Give the attacker access to your system. The attacker can read your files or even modify them.
  • Ransomware — A malicious program that encrypts the user's files. Without knowing the encryption password, the files become unreadable gibberish. The attacker offers to give the decryption password if the user is willing to pay the "ransom". Attacks availability (and potentially confidentiality).
03 — Hands-On Attack

Practical Example of OS Security

In a typical attack, the adversary needs to gain access to a remote system. They can accomplish this by tricking the target into running a malicious file or by obtaining a username and a password. This room focuses on the latter.

After discovering a username, we will try to "guess" the password. Furthermore, we will try to escalate our privileges to a system administrator. This account is called root on Android, Apple, and Linux systems, and administrator on MS Windows systems. The accounts root and administrator have complete unrestricted access to a system.

SSH — Connecting Remotely

ssh username@IPConnect to a remote Linux machine via SSH (Secure Shell). You'll be prompted for a password.

When typing your SSH password, you won't see any stars, dots, or indicators on the screen. The system still receives the password you are typing — this is normal on Linux.

Commands Used in This Exercise

whoamiConfirm which user you're logged in as.

su - johnnySwitch User — Log in as another user (e.g. Johnny). You'll need their password.
historyShows the commands the user has typed previously. Reusing passwords means that your password for other sites becomes exposed if one service is hacked.

Key Insight

By checking history, we found that a user had mistakenly typed their password instead of a command. This exposed their credentials. Then using su, we switched to that user and escalated further. This is a real scenario that happens in corporate environments when users have poor password hygiene.

Key Takeaway

The practical exercise demonstrates a real attack chain: gain initial access (SSH + weak password) → investigate (history, ls, cat) → escalate privileges (su to another user or root). All of this is possible because of weak passwords and poor security practices.

Vocabulary

Key Terms

  • CIA Triad — Confidentiality, Integrity, Availability. The three pillars of cybersecurity.
  • Confidentiality — Only intended persons can access the data.
  • Integrity — Data cannot be tampered with (on disk or in transit).
  • Availability — Systems and data are accessible when needed.
  • Authentication — Verifying identity. Three factors: something you know, are, or have.
  • Principle of Least Privilege — Users should only have access to what they need for their job.
  • File Permissions — Rules controlling who can read, write, or execute a file.
  • Trojan Horse — Malicious program that gives an attacker access to your system.
  • Ransomware — Malicious program that encrypts files and demands payment for decryption.
  • SSH — Secure Shell. Protocol for securely connecting to a remote system (port 22).
  • root — The administrator account on Linux/Android/Apple systems. Full unrestricted access.
  • administrator — The equivalent of root on Windows systems.
  • su — Switch User. Command to log in as another user on Linux.
  • history — Linux command showing previously typed commands. Can leak passwords if users mistype.
  • Privilege Escalation — Going from a low-privilege account to a higher-privilege one (e.g. user → root).

What does Integrity mean?

Something you know (password), something you are (fingerprint), something you have (phone/SMS).
What is the principle of least privilege?
Users should only have access to the files and resources they need for their job — nothing more.
What is ransomware?
A malicious program that encrypts your files and demands payment (ransom) for the decryption key. Attacks availability.
What is the administrator account called on Linux?
root
What command do you use to switch to another user on Linux?
su - username (Switch User)
What command shows previously typed commands on Linux?
history
Why is the history command dangerous from a security perspective?
If a user accidentally types their password as a command, it gets saved in history — exposing credentials to anyone who can access that user's account.
Which CIA pillar does ransomware primarily attack?
Availability (you can't access your files). Also potentially Confidentiality (attacker may read them).
Which CIA pillar do weak file permissions attack?
Confidentiality (unauthorized access) and Integrity (unauthorized modification).
What is privilege escalation?
Going from a low-privilege account to a higher-privilege one (e.g. standard user → root/administrator).
