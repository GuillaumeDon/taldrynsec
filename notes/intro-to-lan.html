01 — How Networks are Shaped

LAN Topologies

A topology is the design or look of the network at hand. Each topology has its own advantages and disadvantages.

Star Topology

Devices are individually connected to a central networking device such as a switch or hub. Most commonly used today because of its reliability and scalability — simple the cost.

  • Pros: Easy to troubleshoot, any malfunctioning device doesn't affect the rest. Easy to add new devices.
  • Cons: The more devices added, the harder maintenance becomes. Costs can rise due to extra equipment (cables, switches).

Bus Topology

All devices share a single connection (a "backbone cable"). Similar to the leaf of a tree.

  • Pros: Cheap and easy to implement — requires less cable.
  • Cons: Very difficult to troubleshoot. Data collisions are frequent (all devices use the same cable). If the backbone cable breaks, no device can transmit data.

Ring Topology

Also known as "token topology". Devices are connected to each other in a loop — each device has exactly two neighbors.

  • Pros: Less strain on the network as data travels in one direction. Dedicated connections between each device.
  • Cons: Not efficient (data can make a whole trip around the ring before arriving). If one cable or device fails, the whole network is affected (single point of failure).

Switch vs Router

Switch
Connects devices within the same network. Keeps a record of MAC addresses of devices. Instead of sending packets to every port, only sends to the device it's intended for. More efficient than a hub.
Router
Connects different networks together. Its job is routing — finding the best path for data travelling across networks to reach its destination. Makes multiple networks successfully delivered.
Key Takeaway

Switch = within a network. Router = between networks. Star topology is the most common today. Bus is cheap but fragile. Ring has single points of failure.

02 — Dividing Networks

A Primer on Subnetting

Subnetting is the process of splitting up a network into smaller, miniature networks. Think of it like slicing a cake — one cake, but everyone wants a piece.

Why Subnet?

In a business, different departments need to talk to each other but also have specific network slices reserved for their own purposes (Accounting, Finance, Human Resources…).

  • Efficiency — Fewer devices per subnet = less congestion.
  • Security — Isolate sensitive departments.
  • Full control — Better management of network traffic.

The Subnet Mask

Subnetting is achieved by splitting up the number of hosts that can fit within the network, represented by a number called a subnet mask.

  • An IP address is 4 octets (32 bits), each octet from 0 to 255
  • A subnet mask is also 4 octets (32 bits)
  • Each octet has 8 bits (0-255)

Three Types of Addresses

Network Address
Identifies the start of the actual network. Used to identify a network's existence. Example: 192.168.1.0
Host Address
Used to identify a device on the subnet. Example: 192.168.1.100
Default Gateway
Special address assigned to a device on the network capable of sending information to another network. Data must go to this address to leave the subnet. Usually .1 or .254 of the network.
Key Takeaway

Subnetting divides a network into smaller parts for efficiency, security, and control. Remember the three address types: Network (start), Host (devices), Default Gateway (exit door).

03 — Finding Devices

ARP — Address Resolution Protocol

Devices have two identifiers: a MAC address (physical) and an IP address (logical). ARP is the technology that links them together.

What ARP Does

ARP allows a device to associate its MAC address with an IP address on the network. Each device keeps a log (called a cache) of the MAC addresses associated with other devices on the network.

How ARP Works — Two Message Types

Device A:
"Who has
192.168.1.10?"
→
ARP Request
(broadcast to all)
→
Device B:
"I do! My MAC

→
ARP Reply

  • ARP Request — A message is broadcast to the entire network asking "What is the MAC address that owns this IP address?"
  • ARP Reply — Other devices receive the message. Only the device that owns that IP address responds with its MAC address.

The requesting device now remembers the IP ↔ MAC mapping and stores it in its ARP cache for future use — no need to ask again.

Key Takeaway

ARP = "Who has this IP?" → "I do, here's my MAC." Without ARP, devices couldn't communicate on a LAN because they need MAC addresses for physical delivery but know each other by IP.

04 — Automatic IPs

DHCP — Dynamic Host Configuration Protocol

IP addresses can be assigned manually (you enter them by hand) or automatically via DHCP (most common). When a device connects to a network without a pre-assigned IP, it sends out a request.

The 4-Step DHCP Handshake

1. DHCP
Discover
→
2. DHCP
Offer
→
3. DHCP
Request
→
4. DHCP
ACK
  • DHCP Discover — "Hey, I'm new here. Is anyone who can give me an IP address?" (sent by the client to find any DHCP servers)
  • DHCP Offer — The DHCP server replies: "Sure thing, you can have 192.168.1.10."
  • DHCP Request — The client accepts: "Yes, that would be brilliant! I'll start using 192.168.1.10."
  • DHCP ACK — The server confirms: "Okay, great. You can use that IP for the next 24 hours."
Key Takeaway

Memorize DORA: Discover → Offer → Request → ACK. Every time you connect to a new Wi-Fi network, this exchange happens behind the scenes in milliseconds.

Vocabulary

Key Terms

  • LAN — Local Area Network. A network of devices in a limited area (home, office).
  • Topology — The design or shape of a network.
  • Star Topology — All devices connect to a central switch/hub. Most common.
  • Bus Topology — All devices share a single backbone cable. Cheap but fragile.
  • Ring Topology — Devices connected in a loop. Data travels one direction.
  • Switch — Connects devices within a network using MAC addresses.
  • Router — Connects different networks together. Finds the best path for data.
  • Subnetting — Dividing a network into smaller sub-networks.
  • Subnet Mask — A number that defines how a network is divided (4 octets, 32 bits).
  • Octet — One of the 4 sections of an IP address (8 bits, 0-255).
  • Network Address — Identifies the start of a network.
  • Host Address — Identifies a specific device on the network.
  • Default Gateway — The device (usually the router) that sends data to other networks.
  • ARP — Address Resolution Protocol. Maps IP addresses to MAC addresses.
  • ARP Request — Broadcast asking "Who has this IP?"
  • ARP Reply — Response from the device that owns the IP, with its MAC.
  • ARP Cache — Local storage of IP ↔ MAC mappings.
  • DHCP — Dynamic Host Configuration Protocol. Automatically assigns IPs.
  • DORA — DHCP handshake: Discover, Offer, Request, ACK.
