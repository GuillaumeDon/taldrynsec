Operating Systems Beginner
01 — Day 2 on the Job

Introduction

After your first steps into the Linux CLI, today you're continuing your journey on Windows — one of the most widely used operating systems in workplaces worldwide. As someone interested in cyber security, you'll often investigate or troubleshoot Windows machines, especially user desktops and laptops.

The Command Prompt (often referred to as CMD) is a text-based interface for interacting with the Windows OS. Instead of clicking folders and menus, you type commands to tell the system exactly what you want to do.

Why the Windows Command Line?

  • Not everything is visible in the graphical interface
  • Files may be hidden or buried deep in the system
  • Analysts often need quick answers without clicking through menus
  • Command-line tools are faster, more precise, and easier to automate
02 — Moving Around

Windows CLI: Navigating Files

Step 1: "Where Am I?" — cd

cdShows the full path of the directory you're currently in. On Windows, this is usually your user folder (e.g. C:\Users\Administrator). Note: cd is used both to display and to change the directory.

Step 2: "What's Around Me?" — dir

dirLists the files and folders in the current directory. Shows dates, sizes, and names.

Not everything you see will always be obvious. Take a moment to look around — not everything is immediately visible.

Step 3: "Are There Hidden Files?" — dir /a

dir /aShows everything, including hidden files and folders. On Windows, some files and folders are marked as hidden — this doesn't mean they're secret, just that Windows hides them by default.

Step 4: "Moving Around" — cd <folder>

cd DocumentsMove into the Documents folder.
cd ..Go back one level (parent directory).

Use dir / dir /a to explore what's inside each folder. You can explore a file system quickly just by combining cd and dir.

Step 5: "Finding a File on the Disk" — dir /s

dir /s task_brief.txtThe /s flag tells Windows to search all subdirectories starting from your current directory. It will find the file and show you the full path to it.

Step 6: "Navigate to the File"

cd path\to\the\folderNow that you know where the file is, use cd to navigate to its location.

Step 7: "Read the File" — type

type task_brief.txtPrints the contents of a file directly in the command prompt. The Windows equivalent of Linux's cat.
Key Takeaway

Windows navigation: cd (where am I / move), dir (what's here), dir /a (show hidden), dir /s filename (search everywhere), type (read file). Same logic as Linux, different commands.

03 — Investigating the Machine

Gathering System Information on Windows

It's time to learn how to ask the system questions about itself. Cyber security and IT professionals do this all the time — before fixing a problem or investigating an incident, they first want to know: who am I, what machine is this, what version of Windows, and how is it connected?

Step 1: "Who Am I?" — whoami

whoamiPrints the username of the account you're currently logged into. This matters because different users can have different permissions.

Step 2: "What Is the Computer's Name?" — hostname

hostnamePrints the computer's network name. In workplaces, this helps identify network systems.

Step 3: "What Version of Windows?" — systeminfo

systeminfoPrints a lot of information about the system. Don't worry, you're not expected to understand everything yet.

Focus on these key parts:

  • OS Name — The version of Windows (e.g. Windows Server 2019 Datacenter).
  • OS Version — The exact build number.
  • System Type — Whether the machine is 32-bit or 64-bit.
  • Total Physical Memory — How much RAM the machine has.

Step 4: "How Is This Machine Connected?" — ipconfig

ipconfigShows the machine's network configuration. This information helps analysts understand how a machine connects to the network.

Key fields to look for:

  • IPv4 Address — The machine's IP address on the local network.
  • Subnet Mask — Defines the network boundary.
  • Default Gateway — The router's IP address (exit point to the Internet).
Key Takeaway

These are the first commands analysts and IT staff run when they start working on a Windows machine: whoami (who), hostname (what machine), systeminfo (what OS/version), ipconfig (network). Memorize all four.

Vocabulary

Key Terms

  • CMD — Command Prompt. Windows text-based interface for system interaction.
  • cd — Change Directory. Shows current path or navigates to a folder.
  • dir — List directory contents (equivalent of Linux ls).
  • dir /a — Show all files including hidden ones.
  • dir /s — Search recursively through all subdirectories.
  • type — Display file contents (equivalent of Linux cat).
  • whoami — Print current username (same on Linux and Windows).
  • hostname — Print the computer's network name.
  • systeminfo — Display comprehensive system information.
  • ipconfig — Display network configuration (IP, subnet mask, default gateway).
  • IPv4 Address — The machine's IP address on the local network.
  • Subnet Mask — Defines which part of the IP is the network vs the host.
  • Default Gateway — The router's IP — the exit point to the Internet.
  • Hidden Files — Files marked as hidden by Windows. Not secret, just not shown by default.
