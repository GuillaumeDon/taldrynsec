01 — Introduction

What is Python?

Python is a high-level, general-purpose programming language. High-level means it hides most implementation details so you focus on logic, not hardware. General-purpose means it covers web apps, automation scripts, data science, machine learning, and more.

In this room, we build a "Guess the Number" game step by step to explore three fundamental programming concepts:

Variables

Named containers that store a value. secret = 10 stores the number 10 under the name secret.

Conditionals

if / elif / else — branches that run different code depending on whether a condition is true or false.

Iterations

while loop — repeats a block of code as long as a condition holds. Gives the player multiple attempts.

02 — Variables

Setting Up the Game State

The program needs to track three values throughout its execution:

  • secret — the randomly picked number the player must guess
  • tries — how many attempts the player has made (starts at 0)
  • guess — the player's current guess (initialised to 0, a value that can never be secret since secret is 1–20)

The Variables Task Code

import random # gives us tools for picking random numbers secret = random.randint(1, 20) # a <= secret <= b tries = 0 guess = 0 # start with a value that cannot be the secret (1..20) print("I'm thinking of a number between 1 and 20") text = input("Take a guess: ") # input() always returns a string guess = int(text) # convert the string to an integer tries = tries + 1 # add 1 try

Key Functions

  • random.randint(a, b) — returns a random integer N such that a ≤ N ≤ b.
  • print("text") — displays text on screen.
  • input("prompt") — reads a line from the user; always returns a string.
  • int(text) — converts a string like "10" to the integer 10. Required before any math comparison.
Key Takeaway

Variables are containers with names. Type matters: input() returns a string, not a number. Always convert with int() before comparing to numeric values, otherwise Python will compare a string to a number — and get it wrong.

03 — Conditional Statements

if / elif / else

After reading the guess, the program compares it to secret and prints an appropriate hint. This requires branching logic: different code runs depending on which condition is true.

if
guess < 1 or guess > 20 → "That number is out of range. Try again."
elif
guess < secret → "Too low, try again."
elif
guess > secret → "Too high, try again."
else
→ "You got it in [tries] tries!" (guess == secret)

First Draft Code (one attempt)

import random secret = random.randint(1, 20) tries = 0 guess = 0 print("I'm thinking of a number between 1 and 20") text = input("Take a guess: ") guess = int(text) tries = tries + 1 if guess < 1 or guess > 20: print("That number is out of range. Try again.") elif guess < secret: print("Too low, try again.") elif guess > secret: print("Too high, try again.") else: print("You got it", tries, "tries!")

Limitation: this version gives the user only one chance. If the guess is wrong, the program exits. We fix this in Task 4 with a loop.

Key Takeaway

Python evaluates if first. If false, it checks each elif in order. If all are false, it runs else. Only one branch executes. elif is Python's way of writing "else if".

04 — Iterations

while Loop

A loop (iteration) lets us run the same block of code multiple times. Instead of giving the player one shot, we keep asking until they guess correctly. Python's while loop repeats as long as a condition is True.

while guess != secret:
— ask for input
— convert to int
— increment tries
— check with if/elif/else and print hint
(loop back to the top and re-check condition)

The condition guess != secret means "guess does not equal secret". When the player finally guesses correctly, guess == secret, so guess != secret becomes False and the loop stops.

Final Complete Program (guess_v1.py)

import random # ---------------------------- # Guess the Number (Beginner Demo) # The computer picks a secret number. # The player keeps guessing until they find it. # ---------------------------- secret = random.randint(1, 20) tries = 0 guess = 0 # start outside valid range so while runs immediately print("I'm thinking of a number between 1 and 20") # Repeat until the user guesses the secret number. while guess != secret: text = input("Take a guess: ") guess = int(text) tries = tries + 1 if guess < 1 or guess > 20: print("That number is out of range. Try again.") elif guess < secret: print("Too low, try again.") elif guess > secret: print("Too high, try again.") else: print("You got it", tries, "tries!")

How the while loop executes — step by step

  • Python checks guess != secret. Initially 0 != secret → True. Enters the loop.
  • Reads the guess, converts to int, increments tries.
  • Runs the if/elif/else block and prints a hint.
  • Goes back to the top — re-evaluates guess != secret.
  • If the guess was correct, condition is now False → loop exits. Game over.
Key Takeaway

A while loop runs as long as its condition is True. The indented block is the loop body. When the condition becomes False, execution continues after the loop. Always make sure the loop can eventually exit — otherwise you have an infinite loop.

Vocabulary

Key Terms

  • High-level language — A language that abstracts hardware details. Python, JavaScript, C# are high-level. Assembly is low-level.
  • Variable — A named storage location holding a value. In Python: x = 5.
  • Type — The kind of data a variable holds: int (integer), str (string), float (decimal), bool (True/False).
  • int() — Python built-in function that converts a string to an integer.
  • input() — Reads a line of user input from the terminal. Always returns a str.
  • print() — Outputs text to the screen.
  • random.randint(a, b) — Returns a random integer between a and b (inclusive).
  • Conditional statement — Code that runs only when a condition is True. Python keywords: if, elif, else.
  • elif — Python's "else if". Checked only if the preceding if was False.
  • Boolean expression — An expression that evaluates to True or False. Uses operators: ==, !=, <, >, <=, >=.
  • Loop / Iteration — Executing the same block of code multiple times.
  • while loop — Repeats a block as long as its condition remains True.
  • != — "Not equal to" operator. guess != secret is True when they differ.
  • Indentation — In Python, indented lines belong to the block above (if, while, etc.). Mandatory — not optional.
  • Infinite loop — A loop whose condition never becomes False. Caused by a logic error; terminates with Ctrl+C.

input(). It always returns a string (str), even if the user types a number.
Why do we need int(text) after reading a guess?
Because input() returns a string. We need an integer to compare with the numeric variable secret. int("10") converts the string "10" to the integer 10.
What does random.randint(1, 20) return?
A random integer N where 1 ≤ N ≤ 20 (both bounds inclusive).
Why is guess initialised to 0 instead of, say, 10?
Because the secret is always between 1 and 20. Setting guess = 0 guarantees guess != secret is True at the start, so the while loop always runs at least once.

elif. Example: elif guess < secret:
What is the difference between = and == in Python?
= is assignment: it stores a value in a variable (x = 5). == is comparison: it checks whether two values are equal and returns True or False.
What does != mean?
"Not equal to". guess != secret is True when guess and secret have different values.
What is a while loop? When does it stop?
A loop that repeatedly executes its indented body as long as its condition is True. It stops the moment the condition evaluates to False.
What will the program display if the user inputs 50 (secret = 10)?
"That number is out of range. Try again." — because 50 > 20, the first if condition is True.
What will the program display if the user guesses correctly in 3 tries?
"You got it 3 tries!" — the else branch runs and prints tries, which equals 3.
What is indentation in Python and why does it matter?
Indented lines (spaces/tab at the start) define which block a statement belongs to — if body, while body, etc. Python enforces indentation; wrong indentation causes errors or unexpected behaviour.
What are the three key pillars of imperative programming covered in this room?
Variables (storing state), Conditionals (if/elif/else branching), and Iterations (while loops).
What is an infinite loop? How do you stop one in the terminal?
A loop whose condition never becomes False, so it runs forever. Stop it with Ctrl+C in the terminal.
