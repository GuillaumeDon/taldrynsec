Linux CLI Basics

Get comfortable navigating through the Linux CLI.

Linux Beginner
01 — Why Linux CLI Matters

Introduction

In cyber security, Linux is everywhere — powering servers, security tools, and even hacking environments. Before you can defend systems or investigate incidents, you need to know how to navigate the Linux OS using the command-line interface (CLI).

Why the Terminal?

  • It's faster than clicking around
  • It gives you more control
  • Many security tools only run in the terminal

The Scenario

It's your first day as an IT Support Engineer with the Cyber Operations Support Team. Your supervisor left in a hurry to deal with an incident and left you a note: "Most of our work happens in the Linux terminal. Start by opening the terminal and exploring a bit."

Key Takeaway

CLI stands for Command-Line Interface. It's a text-based interface where you type commands to control the computer. In cybersecurity, it's your primary tool — most of the work happens here.

02 — Moving Around

Navigation Mission

Step 1: "Where Am I?" — pwd

pwdPrint Working Directory — Shows you the folder you're currently in.

Step 2: "What's Around Me?" — ls

lsLists the content of the current directory (files and folders).
ls -lLong format — shows file sizes, permissions, dates, and more.
ls -alLong format + hidden files. Hidden files start with a dot (.) and Linux hides them by default.

Step 3: "Let's Move Around" — cd

cd DocumentsChange Directory — Moves into the Documents folder.
cd ..Go back one level (to the parent directory).
cd ~Go back to your home directory (shortcut).

Step 4: "Find a File" — find

find ~ -name filename.txtSearch for a file by name starting from your home directory (~). Checks every folder inside.

If the file exists, Linux will print the full path to it. You can then use cd to navigate to the folder and cat to read it.

Step 5: "Read a File" — cat

cat filename.txtDisplays the content of a file in the terminal.
The 5 Essential Navigation Commands

pwd (where am I?), ls (what's here?), cd (move), find (search), cat (read). These 5 commands are what you'll use 90% of the time in any Linux environment.

03 — Gathering Intel

Investigating the System

Your next assignment: collect a small system report. In cybersecurity, gathering system information helps teams understand what environment they're operating in — what version of Linux, what resources are available. Think of it as taking a quick health check of the machine.

Step 1: "Who Am I?" — whoami

whoamiPrints your current username. One of the simplest and most useful commands in Linux.

Step 2: "What System Am I On?" — uname

uname -aGives a full line of system information: kernel, hostname, kernel version, hardware platform, OS type.
unameOutputs just the operating system name (e.g. Linux).

Breakdown of uname -a Output

  • Linux — The system is running the Linux kernel.
  • tryhackme — The hostname (the computer's name).
  • Kernel version — The kernel version installed on the machine.
  • x86_64 — The hardware platform (also 64-bit).
  • GNU/Linux — The operating system type (Linux kernel + GNU tools).

Step 3: "Check Disk and Storage" — df

df -hDisplays disk usage in human-readable format (GB/MB instead of bytes).

Key entries in the output:

  • /dev/root — The main disk of the system. Shows total, used, free space, and percentage full.
  • tmpfs — Temporary filesystems stored in RAM, not on the physical disk.
  • /dev/shm — Shared memory area.

Step 4: "Read a System File" — /etc

Linux stores configuration and informational files in the /etc directory. To explore it:

cd /etcNavigate to the system configuration directory.
lsList all config files — you'll see dozens: hosts, passwd, fstab, os-release, etc.
cat os-releaseShows the Linux distribution details: name, version, pretty name, support URLs.

The os-release file provides details about the Linux distribution that are often clearer than those provided by uname.

Key Takeaway

whoami (who am I?), uname -a (what system?), df -h (disk space?), cat /etc/os-release (what distro?). These 4 commands let you quickly profile any Linux machine — essential for incident response and system administration.

04 — Recap

What You Learned

  • Navigate the Linux filesystem
  • Search for files
  • Inspect system information
  • Read important configuration files
  • Follow clues and complete missions inside a Linux environment

These skills may seem simple, but they're the building blocks for everything that comes later: file permissions, users & groups, processes, package management, and eventually real security tooling.

Vocabulary

Key Terms

  • CLI — Command-Line Interface. Text-based way to control the computer.
  • Terminal — The application that provides access to the CLI.
  • pwd — Print Working Directory.
  • ls — List directory contents.
  • cd — Change Directory.
  • find — Search for files by name across directories.
  • cat — Concatenate/display file content.
  • whoami — Display current username.
  • uname — Display system information (kernel, hostname, architecture).
  • df — Disk Free. Show disk space usage.
  • Hidden Files — Files starting with a dot (.). Hidden by default, shown with ls -a.
  • Home Directory — Your personal folder. Shortcut: ~. Usually /home/username.
  • /etc — System configuration directory. Contains config files like os-release, passwd, hosts.
  • os-release — File in /etc with details about the Linux distribution.
  • Kernel — The core of the OS that manages hardware and system resources.
  • Hostname — The computer's network name.
  • x86_64 — 64-bit hardware architecture.
  • tmpfs — Temporary filesystem stored in RAM.
