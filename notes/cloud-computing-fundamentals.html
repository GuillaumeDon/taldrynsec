01 — The Problem Cloud Solves

Why Cloud Computing?

Imagine you have a fantastic idea for an app that helps students practice cybersecurity, and you host it on your own computer. Problems arise quickly:

  • Users from other parts of the world experience lag
  • Many users connecting at once overwhelm your machine
  • If your computer is off, the app is down

These limits make it hard for the app to grow. That's when cloud computing solves these problems.

What This Room Covers

  • What is cloud computing
  • Service models: IaaS, PaaS, SaaS
  • Cloud types: Private, Public, Hybrid
  • Benefits of cloud computing
  • How big companies use the cloud
Key Takeaway

The cloud is built on top of virtualization and containers. These technologies run many applications efficiently on shared infrastructure, and allow quick creation/modification of environments on demand.

02 — The Concepts

Cloud Computing Overview

Evolution to the Cloud

Cloud computing didn't appear suddenly — it's the result of many years of change:

  • Physical Servers Era (1960s–early 2000s) — Physical servers in company buildings. One server = one job. Expensive, slow to scale.
  • Virtualization (1999–2006) — Multiple virtual servers on one machine. Better hardware utilization, faster provisioning.
  • Automation & Remote Management (2000–2006) — Servers managed over the Internet. Early automation. Flexible infrastructure.
  • Cloud Computing (AWS Launch, 2006) — Rent virtual computers & storage on demand. No hardware ownership. Elastic scaling in minutes.
  • Modern Cloud Era (2015+) — AWS, Azure, Google Cloud. Containers. Focus on apps, not servers. Global-scale platforms.

Cloud Benefits & Characteristics

  • Scalability — Easily scale up or down as the company's needs change.
  • On-demand self-service — Create or remove servers and storage instantly, without waiting for hardware.
  • Pay only for what you use — Charged based on usage, not upfront costs.
  • Security — Cloud providers protect the infrastructure with strong security measures.
  • High availability — Applications keep running even if part of the system fails.
  • Global access — IT resources can be accessed by users anywhere in the world.

Types of Cloud (Deployment Models)

Public Cloud
Used by startups, websites, and global apps. Affordable, easy to scale, no infrastructure management. Preferable for nearly every use case.
Private Cloud
Used by banks, healthcare, and government. Greater control, customization, and compliance for sensitive data.
Hybrid Cloud
Used by companies like e-commerce platforms that need to keep sensitive data private while scaling publicly during high demand.

Cloud Service Models — IaaS, PaaS, SaaS

Think of these like different ways of renting a place to live:

IaaS — Infrastructure as a Service
Renting an empty apartment. You rent basic computing resources (virtual servers, storage, networking). You manage the OS and your apps. The provider manages the physical hardware.
PaaS — Platform as a Service
Renting a semi-furnished apartment. The cloud provider manages the infrastructure AND the OS. You focus on building, deploying, and running your app — no server worries.
SaaS — Software as a Service
Staying in a hotel. Complete application over the Internet. The provider manages everything. You just use it via a browser or app (Gmail, Zoom).

Major Cloud Vendors

  • AWS (Amazon Web Services) — Industry leader with the most extensive offerings and global reach.
  • Microsoft Azure — Strong competitor, especially in enterprise and hybrid cloud environments.
  • Google Cloud Platform (GCP) — Known for data analytics, AI, and machine learning tools.
  • Alibaba Cloud — A major player in Asia, offering competitive cloud services globally.
  • IBM Cloud — Focuses on hybrid cloud and AI-driven solutions for businesses.
  • Oracle Cloud — Focuses on enterprise applications and databases.

Real-World Examples

  • Netflix — Runs its entire platform on AWS to scale globally and stream reliably to millions.
  • Spotify — Uses the cloud to handle millions of songs and users, scaling during new releases.
  • Instagram — Stores and delivers massive amounts of photos and videos.
  • Online stores — Handle traffic spikes during Black Friday without permanent infrastructure.
Key Takeaway

Remember the apartment analogy for service models: IaaS = empty apartment, PaaS = semi-furnished, SaaS = hotel. And the 3 deployment types: Public (shared, cheap), Private (dedicated, secure), Hybrid (mix of both).

03 — Hands-On

Deploying a Cloud Instance

This task simulates deploying a cybersecurity training app in a simulated AWS environment. The goal is to memorize key buttons and understand how cloud resources are created and managed in real-world use.

Basic Cloud Terminology (AWS)

  • EC2 (Elastic Compute Cloud) — AWS's virtual computers in the cloud. Like having a CPU and memory (RAM) you can rent and use remotely.
  • Instance Type — Describes the essential characteristics of a virtual computer. Bigger instance = more power = higher cost. Example: t1.micro, m1.large.
  • Region — A geographical location where AWS resources live (e.g. Europe, North America).

Key Actions

  • Create Virtual Machines — Launch new instances (e.g. application-interface, m1.large).
  • Start / Stop Instances — Control when you pay. Stopped instances cost 0 credits.
  • Billing Analysis — Navigate to the Billing tab to see how much each instance costs per month.
  • Cost Optimization — Stop unused VMs to reduce the bill. This is a real-world skill.
Key Takeaway

In the cloud, you pay for what you use. Forgetting to stop instances = a big bill. Part of cloud security and management is resource hygiene — knowing what's running and why.

04 — Recap

Key Terminology Recap

Cloud Types

  • Public Cloud — Cloud services you access over the Internet that many people and companies share.
  • Private Cloud — A cloud built just for one company, for more control and security.
  • Hybrid Cloud — A mix of public and private clouds that can work together and share data.

Service Models

  • IaaS — Rent basic computer parts like servers and storage from the cloud.
  • PaaS — A ready-to-use environment to build and run apps without managing servers.
  • SaaS — Software you use online without installing anything (Gmail, Zoom).

AWS-Specific

  • EC2 — Amazon's cloud computers you can quickly create, use, and resize.

Key Benefits

  • Scalability
  • On-demand self-service
  • Pay only for what you use
  • Security
  • High availability
  • Global access
Vocabulary

Key Terms

  • Cloud Computing — Delivery of computing resources (servers, storage, apps) over the Internet.
  • Virtualization — Technology that creates virtual versions of hardware, allowing multiple virtual servers on one physical machine.
  • Containers — Lightweight way to package apps with their dependencies, for fast deployment.
  • Public Cloud — Shared cloud services (AWS, Azure, GCP).
  • Private Cloud — Dedicated cloud for a single organization.
  • Hybrid Cloud — Mix of public and private clouds.
  • IaaS — Infrastructure as a Service. Rent raw computing resources.
  • PaaS — Platform as a Service. Rent a development/runtime environment.
  • SaaS — Software as a Service. Use software over the Internet.
  • AWS — Amazon Web Services. Industry-leading cloud provider.
  • EC2 — Elastic Compute Cloud. AWS's virtual computers service.
  • Instance — A virtual machine in the cloud.
  • Instance Type — The specs of a VM (CPU, RAM). Bigger = more expensive.
  • Region — Geographical location of cloud resources.
  • Scalability — Ability to grow or shrink resources based on demand.
  • High Availability — Systems keep running even if parts fail.
