01 — The Scenario

Introduction

Every OS has its own personality. If you've used a computer at school, work, or home, there's a good chance you've already met Microsoft Windows — the most familiar OS. This room lets you step into a real example and see how the previously learned concepts take shape.

You take on the role of a new employee starting your first day at TryHatMe. You'll log in to your Windows workstation, learn the interface, open tools, navigate folders, create and organize files, change system settings, check Task Manager, and review basic security settings.

Windows History — Key Milestones

  • MS-DOS — Early text-based OS, the foundation before Windows had a GUI.
  • Windows 3.1 (1992) — One of the first graphical versions.
  • Windows XP (2001) — Massively popular, unified home and professional editions.
  • Windows 7 (2009) — Refined the experience after Vista.
  • Windows 10 (2015) — Long-running OS, now reaching end of life.
  • Windows 11 (2021) — Current consumer release with redesigned interface.
02 — Navigating Windows

Exploring the Windows Workspace

Logging In and Authentication

The authentication process controls who can access your desktop and determines the actions you're allowed to take. Windows has three main account types:

  • Administrator — Full control over the system: install software, manage applications, change security settings, and system functionality.
  • Standard — Can do everyday tasks (open apps, browse, manage own files) but cannot install software or change system-wide settings without a password prompt.
  • Guest (deprecated) — Limited access, restricted by permissions. Mostly phased out.

Upon startup, if only one account exists, you're automatically logged in as Administrator. This lets you explore system settings, install programs, and modify the environment — but is not recommended for daily use due to security risks.

The Windows Desktop

The desktop is like an airport — a central hub that connects different areas. Two main areas:

  • Desktop — The main workspace where files, folders, and shortcuts live.
  • Taskbar — A control strip that provides access to applications, system tools, settings, and notifications.

Taskbar Components

  • Start Menu — Primary way to access applications, settings, and power options. Signified by the Windows logo. Fully customizable.
  • Search — Quick access method for locating applications, settings, and files.
  • Task View — Allows you to see all currently open windows and quickly switch between them.
  • Pinned Applications — Your most-used apps, pinned for quick access.
  • System Tray — Shows background services: Wi-Fi, volume, battery, etc.
  • Date and Time — Opens a full calendar, clock, and settings (access alarms too).
  • Notification Panel — Displays messages from the OS and apps (updates available, security alerts, etc.).

Built-in Tools and Apps

Windows ships with useful built-in tools and applications. Beyond the web browser, you'll use: Calculator, Notepad, Paint, File Explorer, Snipping Tool — all accessible from the Start menu.

Getting System Information

Windows includes a tool called Settings that allows you to configure your OS and learn details about your system. The "About your PC" section in Settings provides key details about the system: device name, processor, RAM, Windows edition, and version.

The "About this PC" provides: device specifications (processor, RAM, system type), and Windows specifications (edition, version, build number).

File Exploration and Management

File Explorer is the built-in Windows tool to browse, manage, and organize files and folders. Windows organizes files in a hierarchical directory structure: files live inside folders, folders live inside other folders (directories), and each folder or file has a path (address) to its location.

To access File Explorer: click the File Explorer (folder) icon on the Desktop, or alternatively press Win + E.

File Explorer features:

  • Navigation panel on the left to browse drives and folders
  • Options for creating, sharing, and sorting folders and files
  • File path bar (address bar) for direct navigation
  • Search functionality to find files by name or content
03 — Security and Configuration

Configuring and Securing Windows

Updating Your Applications

Keeping your system and applications up to date is an essential part of maintaining your system's security. Updates often include critical security patches, performance improvements, and bug fixes.

  • Windows Update — Built-in update tool that keeps the OS and some other applications up to date. Windows Update can be accessed through the Settings app, appearing in your system configuration.
  • Application Updates — Some apps auto-update, some need manual checking, some redirect to the vendor's website.

Installing and Uninstalling Applications

  • Microsoft Store — The native Windows application for installing trusted applications in a safe environment.
  • Third-party — Apps downloaded from a vendor's website (e.g. .exe or .msi files). Be careful: always download from trusted sources.
  • Dynamic Desktops — Navigate in File Explorer to browse, install, and manage applications with the taskbar and Start menu.

To uninstall: Start menu → right-click → Uninstall, or use the Apps & Features section in Settings.

Diving Into Settings

  • Windows Settings — A centralized, modernized interface for configuring system, device, personalization, and security settings.
  • Control Panel — The legacy management interface that provides access to system configuration options. Still available but being gradually replaced by Settings.

The Task Manager

Task Manager is a built-in Windows tool that allows you to monitor what's happening on your system in real time. It shows you all running applications (and background processes), and lets you end unresponsive ones or check if something suspicious is running.

Key tabs in Task Manager:

  • Processes — Currently running apps and background processes, and their resource usage.
  • Performance — Live graphs for CPU, memory, disk, and network activity.
  • Startup — Apps configured to start when Windows boots. Useful for troubleshooting slow boot times.
  • Details — Expanded view of all processes with PIDs, status, and resource details.
  • Services — Windows services and their current status (running/stopped).

Native Windows Security

Windows has built-in security features that help protect your system from threats. These are not replacements for third-party tools, but are foundational and always active.

Windows Security is a central dashboard for managing Windows built-in security tools. It includes several key areas:

  • Virus & threat protection — Detect and remove malicious software using built-in antivirus.
  • Account protection — Manage login security and identity.
  • App & browser control — Protect users from potentially unsafe apps, files, and websites.

Windows Defender Firewall

Windows Defender Firewall is a built-in firewall designed to help protect your system from unauthorized network traffic. It monitors network connections and applies rules that you or Windows configure, allowing you to enable custom rules or block specific applications from accessing the network.

Firewall has three network profiles:

  • Domain — Used when connected to an organization's managed network.
  • Private — Intended for trusted networks, such as at home or lab environments.
  • Public — Used for untrusted networks (airports, coffee shops, public Wi-Fi).

Advanced settings allow you to: see all inbound/outbound/connection security rules, add/modify custom rules (allowing specific apps, ports, protocols), and create new rules for specific scenarios.

Vocabulary

Key Terms

  • Administrator Account — Full system control: install software, change settings, manage everything.
  • Standard Account — Everyday tasks only, can't change system-wide settings without a password prompt.
  • Desktop — Main workspace with files, folders, shortcuts.
  • Taskbar — Bottom strip: Start Menu, Search, pinned apps, system tray, clock.
  • Start Menu — Main entry point to apps, settings, power options.
  • Task View — View all open windows and switch between them.
  • System Tray — Background services area (Wi-Fi, volume, battery).
  • File Explorer — Browse, manage, and organize files/folders. Shortcut: Win + E.
  • File Path — The address/location of a file in the directory hierarchy.
  • Windows Update — Keeps OS and apps updated with security patches.
  • Microsoft Store — Official app store for trusted application installs.
  • Windows Settings — Modern centralized configuration panel.
  • Control Panel — Legacy configuration interface (still available).
  • Task Manager — Real-time system monitoring (processes, performance, startup). Shortcut: Ctrl+Shift+Esc.
  • PID — Process ID. Unique number identifying each running process.
  • Windows Security — Central dashboard for built-in security tools.
  • Virus & Threat Protection — Built-in antivirus/antimalware scanning.
  • Windows Defender Firewall — Built-in firewall managing network traffic rules.
  • Domain/Private/Public Profiles — Three firewall profiles for different network trust levels.
  • Inbound Rule — Firewall rule controlling incoming traffic.
  • Outbound Rule — Firewall rule controlling outgoing traffic.
