01 — Accessing Linux via SSH

What Is SSH?

SSH (Secure Shell) is a protocol that allows you to remotely log in to and control the terminal of another machine over a network. Any data sent is encrypted in transit — making it safe to use over the internet.

SSH is the standard way to administer Linux servers, connect to CTF machines, and interact with cloud instances. It requires two things:

  • The IP address of the remote machine
  • Valid credentials — username and password (or a key)
SSH syntax
user@local:~$ ssh tryhackme@MACHINE_IP
The authenticity of host can't be established. Are you sure you want to continue? yes
tryhackme@MACHINE_IP's password: (type password — no text shown)
tryhackme@linux2:~$ ← now on the remote machine

Note: when typing a password in SSH, no text or symbols appear — this is normal. Just type the password and press Enter.

Key Takeaway

SSH syntax: ssh username@IP_ADDRESS. All commands you run after connecting execute on the remote machine, not your local one. SSH is used in virtually every real-world Linux administration and pentesting scenario.

02 — Flags & Switches

Extending Command Behaviour

Most Linux commands allow arguments called flags or switches — identified by a hyphen and a keyword. They modify how a command behaves without changing what it does fundamentally.

ls flags
tryhackme@linux2:~$ ls
folder1
tryhackme@linux2:~$ ls -a
.hiddenFolder   folder1

The -a flag (short for --all) reveals hidden files and folders — those starting with a dot (.). Without it, ls ignores them by default.

Getting Help — --help and man

Commands that accept flags usually have a --help option listing all available flags with brief descriptions. For deeper documentation, use the man page:

help & man
tryhackme@linux2:~$ ls --help
Usage: ls [OPTION]... [FILE]...
-a, --all do not ignore entries starting with .
-h, --human-readable print sizes in human readable format
tryhackme@linux2:~$ man ls
LS(1) User Commands LS(1)
NAME: ls — list directory contents
(press q to quit)

Navigate man pages with the arrow keys. Press q to quit. The flag --human-readable (-h) displays file sizes in KB/MB/GB format instead of raw bytes.

Key Takeaway

When stuck: command --help for a quick list, man command for full documentation. ls -a shows hidden files. Hidden files start with a dot — critical in CTFs and security audits where config files are often hidden.

04 — Permissions 101

Who Can Read, Write, Execute?

Linux is multi-user. Every file and directory has a set of permissions that controls what each user can do with it. Run ls -l to see permissions.

ls -l permissions output
tryhackme@linux2:~$ ls -l
-rwxr-xr-- 1 cmnatic cmnatic 0 Feb 19 10:37 file1
-rw-r--r-- 1 cmnatic cmnatic 0 Feb 19 10:37 file2

Permissions Are Split Into 3 Groups

First 3 bits
rwx

Owner — the user who owns the file. Has the most control.

Next 3 bits
r-x

Group — users in the assigned group. Shared access.

Last 3 bits
r--

Others — everyone else on the system.

Each group has 3 bits: r (read=4), w (write=2), x (execute=1). A dash - means that permission is not granted.

Numeric (Octal) Permissions

Permissions are often written as numbers. Add the values of granted permissions per group:

SymbolNumericMeaning
rwx7Read (4) + Write (2) + Execute (1) — full control
rw-6Read (4) + Write (2) — read and edit, no execute
r-x5Read (4) + Execute (1) — read and run, no write
r--4Read only
---0No permissions at all

Example: rwxr-xr-- = Owner:7, Group:5, Others:4 → 754

Common patterns: 777 (everyone can do everything — dangerous), 755 (owner full, others read+execute), 644 (owner read+write, others read only).

Switching Users — su

su — switch user
tryhackme@linux2:~$ su user2
Password: ****
user2@linux2:/home/tryhackme$
tryhackme@linux2:~$ su -l user2
user2@linux2:~$ ← -l inherits user2's home and environment

The -l switch makes the shell behave as if the user logged in directly — inheriting their environment variables and landing in their home directory.

Key Takeaway

Permissions = rwx for Owner / Group / Others. Read=4, Write=2, Execute=1. Add them: rwx=7, rw-=6, r-x=5, r--=4. ls -l shows permissions. su username switches user. su -l username fully inherits their session. Understanding permissions is essential for privilege escalation in CTFs.

05 — Common Directories

Key Linux Filesystem Locations

Linux has a standardised directory structure. These 4 directories are the most important for security professionals to know.

/etc

Stores system-wide configuration files. One of the most important directories on the system. Contains the passwd and shadow files — which store user accounts and hashed passwords.

shadow · passwd · sudoers · sudoers.d
/var

Short for variable data. Stores data that is frequently written by services and applications — especially log files in /var/log. Also contains databases and other non-user-specific data.

backups · log · opt · tmp
/root

The home directory of the root (administrator) user. Unlike other users whose home is at /home/username, root's home is at /root. Often contains sensitive files in CTFs.

myfile · myfile2 · passwords.xlsx
/tmp

Short for temporary. Volatile — contents are cleared on reboot. Any user can write here by default. Pentesters use it to store enumeration scripts and dropped files during an engagement.

todolist · trash.txt · rubbish.bin
Key Takeaway

/etc = configs + credentials. /var/log = logs. /root = root's home. /tmp = writable by everyone, cleared on reboot (attacker's staging area). In CTFs and pentests, these 4 directories are always the first places to investigate.

Vocabulary

Key Terms & Commands

  • SSH (Secure Shell) — Protocol for securely connecting to a remote machine's terminal over a network. Default port: 22.
  • Flag / Switch — An argument added to a command (e.g. -a, --help) that modifies its behaviour.
  • ls -a — List all files including hidden ones (files starting with .).
  • ls -l — Long listing — shows permissions, owner, size, and modification date.
  • man — Manual pages. man ls opens full documentation for the ls command. Navigate with arrow keys, quit with q.
  • touch — Create a new empty file.
  • mkdir — Create a new directory.
  • cp — Copy a file. cp source destination
  • mv — Move or rename a file. mv oldname newname
  • rm — Remove a file. rm -R directory removes a directory recursively.
  • file — Determine the type of a file from its contents (not extension).
  • su — Switch User. su username logs in as another user. su -l username fully inherits their environment.
  • Permissions (rwx) — r=read(4), w=write(2), x=execute(1). Applied to Owner, Group, and Others separately.
  • chmod — Change permissions. chmod 755 file
  • /etc — System configuration files. Contains passwd and shadow (password hashes).
  • /var/log — Log files from services and applications.
  • /root — Home directory of the root user.
  • /tmp — Temporary files. World-writable. Cleared on reboot.

What is the SSH command syntax to connect to a remote machine?
ssh username@IP_ADDRESS — Example: ssh tryhackme@10.10.243.83
What is a flag/switch in Linux commands?
An argument starting with a hyphen (e.g. -a, --help) that modifies a command's behaviour without changing what it fundamentally does.
What flag makes ls show hidden files?
ls -a (short for --all). Hidden files start with a dot (.) and are invisible without this flag.
How do you open the manual page for a command? How do you exit it?
man <command> — Example: man ls. Navigate with arrow keys. Press q to quit.
What command creates a new empty file?
touch filename — Example: touch note.txt
How do you remove a directory in Linux?
rm -R directoryname — the -R flag is required for recursive deletion of directories and their contents.
What is the difference between cp and mv?
cp copies the file (original stays). mv moves or renames it (original is gone from the source location).
What does the file command do?
Determines the type of a file based on its contents — not its extension. Useful when extensions are missing, changed, or misleading.
What do the rwx letters mean in Linux permissions?
r = read (4), w = write (2), x = execute (1). A dash (-) means that permission is not granted.
Permissions -rwxr-xr-- — what are the numeric values for each group?
Owner: rwx = 7 (4+2+1). Group: r-x = 5 (4+0+1). Others: r-- = 4 (4+0+0). Numeric: 754.
What does chmod 777 mean? Why is it dangerous?
Everyone (owner, group, others) has full read+write+execute permissions. Dangerous because any user on the system can modify or execute the file.
What is the difference between su user2 and su -l user2?
su user2 switches to user2 but keeps the current environment. su -l user2 fully inherits user2's environment, variables, and home directory — as if they just logged in.
What is stored in /etc? Why is it important for security?
System configuration files. It contains passwd (user accounts) and shadow (hashed passwords) — critical targets during privilege escalation and credential harvesting.
What is /tmp and why do attackers use it?
The temporary directory — writable by any user by default, cleared on reboot. Attackers use it to upload and stage scripts, exploits, and tools without needing elevated permissions.
Where are log files stored on a Linux system?
/var/log — the variable data directory. Log files from services, applications, and the OS are written here. Essential for incident response and forensics.
