01 — Introduction

Why Computers Use Binary

Humans use the decimal system (base-10) in everyday life — digits range from 0 to 9. Computers, however, are limited to two digits: 0 and 1. This mirrors the physical reality of electronics: a transistor is either conducting current (1) or not (0), a hard-disk particle is magnetized North or South, a light is on or off.

Everything a computer does — storing colors, numbers, text, files — ultimately comes down to sequences of 0s and 1s.

The Four Number Systems

Decimal

Base-10

Digits: 0–9. Our everyday counting system.

Binary

Base-2

Digits: 0, 1. Native language of computers.

Hexadecimal

Base-16

Digits: 0–9, A–F. Compact binary notation.

Octal

Base-8

Digits: 0–7. Groups 3 bits together.

Key Takeaway

Computers use binary because their hardware has only two physical states. Every other system (hex, octal) is just a more human-friendly way to read binary — grouping bits to make them shorter to write and easier to scan.

02 — Representing Colors

From 8 Colors to 16 Million

Our First Eight Colors (1 bit per channel)

A computer screen mixes Red, Green, and Blue light. Think of three knobs, each controlling one color. If each knob can only be on (1) or off (0), you get 2 × 2 × 2 = 8 possible colors. Each color is stored as a 3-bit value called a bit.

From 8 to 16,777,216 Colors (1 byte per channel)

8 colors is not enough. If instead each channel has 8 bits (1 byte) — values from 0 to 255 — we get 256 × 256 × 256 = 16,777,216 colors. A full color is now 3 bytes = 24 bits.

For example, the green used on this page is stored as the binary sequence 01010000 11001100 10010001 — representing decimal values 80, 204, 145 — and written in hex as #00E5A0.

Hexadecimal Representation

Writing 24-bit binary numbers is tedious. Instead, we group every 4 bits into one hex digit. A hex digit ranges from 0 to F, representing decimal 0–15. This means one color byte (8 bits) = exactly 2 hex digits.

So #FF0000 = red (R=255, G=0, B=0), #00FF00 = green, #0000FF = blue.

Key Takeaway

In real applications: a color = 3 bytes (24 bits). Each byte = one channel (R, G, B). Each byte = 2 hex digits. That's why HTML colors look like #RRGGBB. Over 16 million combinations fit in just 3 bytes.

Key Takeaway

Hex groups 4 bits → 1 hex digit. Octal groups 3 bits → 1 octal digit. Both exist only to make binary easier to read. In cybersecurity, hex is everywhere — hex editors, memory addresses, color codes, hash outputs, shellcode. Learn to convert fluently.

Vocabulary

Key Terms

  • Bit — Short for binary digit. Can be 0 or 1. The smallest unit of data.
  • Byte — A group of 8 bits. On modern systems, the standard unit. Also called an octet.
  • Binary (Base-2) — Number system with only digits 0 and 1. The native language of computers.
  • Decimal (Base-10) — Everyday number system. Digits 0–9.
  • Hexadecimal (Base-16) — Digits 0–9 then A–F. Every 4 bits = 1 hex digit. Used everywhere in computing.
  • Octal (Base-8) — Digits 0–7. Every 3 bits = 1 octal digit. Less common, seen in Unix file permissions.
  • RGB — Red, Green, Blue. The three primary colors of light used by computer screens.
  • Hex Color — A 6-character hex string representing a color as #RRGGBB (e.g. #FF0000 = red).
  • MSB — Most Significant Bit. The leftmost bit, with the highest positional value.
  • LSB — Least Significant Bit. The rightmost bit, with the lowest positional value (2⁰ = 1).
  • 24-bit color — 3 bytes (one per channel R, G, B), giving 16,777,216 possible colors.
  • Positional notation — Each digit's value depends on its position. Digit × base^position.

Why do computers use binary instead of decimal?
Because computer hardware has only two physical states: on/off, high/low voltage, magnetized North/South. Binary maps directly to these states.
How many colors can you represent with 1 bit per RGB channel?
8 colors (2 × 2 × 2 = 2³ = 8).
How many colors can you represent with 1 byte per RGB channel?
16,777,216 colors (256 × 256 × 256 = 2²⁴). This is called 24-bit color or "True Color".
How many bytes does a full color take in a 24-bit color system?
3 bytes — one byte per channel (Red, Green, Blue).
What is a hexadecimal digit? What range does it cover?
A single symbol representing values 0–15. Digits 0–9 cover 0–9, and letters A–F cover 10–15. One hex digit = 4 bits.
Convert binary 1010 to decimal.
1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 8 + 0 + 2 + 0 = 10.
Convert binary 1111 to decimal.
1×8 + 1×4 + 1×2 + 1×1 = 15. In hex: F.
What decimal number does hex A represent? Hex F?
A = 10, F = 15.
Why do we use hexadecimal in computing?
It compresses binary into a much shorter notation: 4 bits = 1 hex digit. A full byte (8 bits) needs only 2 hex characters instead of 8 binary digits.
What does the HTML color #FF0000 represent?
Pure red. R = FF (255), G = 00 (0), B = 00 (0).
What is the octal system? How many bits does each octal digit represent?
Base-8 system, digits 0–7. Each octal digit represents 3 bits.
What is a bit? What is a byte?
A bit is the smallest unit of data — 0 or 1. A byte is 8 bits, also called an octet.
What is positional notation?
A system where each digit's value = digit × base^position. The rightmost position is 0. Used in all number systems (decimal, binary, hex, octal).
Convert hex B to binary.
B = decimal 11 = binary 1011.
How do you convert a large binary number to hex quickly?
Group the bits from right to left into groups of 4, then convert each group to its hex digit. Example: 10101111 → 1010 = A, 1111 = F → AF.
