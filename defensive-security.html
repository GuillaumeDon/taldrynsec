Defensive Security Intro

Threat Intelligence · SOC · DFIR · Malware Analysis · SIEM

01 — Key Area

Security Operations Center (SOC)

A team of cybersecurity professionals that monitors the network and its systems to detect malicious events.

Core Responsibilities

  • Vulnerabilities — Discover and patch flaws before they are exploited (not always assigned to the SOC).
  • Policy Violations — Detect actions that break security rules (e.g. uploading confidential data).
  • Unauthorized Activity — Spot logins with stolen credentials or illegitimate access.
  • Network Intrusions — Detect and block intrusions as fast as possible to limit damage.
Key Takeaway

The SOC relies on a SIEM (Security Information and Event Management) to collect and aggregate logs from multiple sources and detect anomalies.

02 — Key Area

Threat Intelligence

Intelligence gathered about current and potential adversaries to help the company prepare its defenses.

Intelligence Cycle

  • Collect — Network logs, public sources, forums…
  • Process — Structure the data into a usable format for analysis.
  • Analyze — Identify the threat actor and predict their next moves.
  • Recommend — Propose an adapted response strategy.
Key Takeaway

Knowing the adversary's TTPs (Tactics, Techniques, and Procedures) allows you to anticipate attacks and adapt your defenses.

03 — Key Area

Digital Forensics & Incident Response (DFIR)

Digital Forensics

The application of science to investigate digital evidence related to a crime or attack.

  • File System — Analyze a disk image to find installed, created, deleted or encrypted files.
  • System Memory — Dump RAM if the malware doesn't save itself to disk.
  • System Logs — Logs reveal the history of events on the machine.
  • Network Logs — Network packets show whether an attack is in progress.

04 — Key Area

Malware Analysis

The study of malicious software to understand how it works.

Virus
Attaches to a program and spreads when executed. Can alter, delete or encrypt files.
Trojan Horse
Looks like a legitimate program but hides a malicious function underneath.
Ransomware
Encrypts the victim's files and demands a ransom to decrypt them.
Spyware
Silently monitors the user (keystrokes, screenshots…).

Analysis Methods

  • Static Analysis — Inspect the code without executing it (requires assembly knowledge).
  • Dynamic Analysis — Run the malware in a controlled environment (sandbox) and observe its behavior.
