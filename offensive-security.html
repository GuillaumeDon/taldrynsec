01 — The Big Picture

What is Offensive Security?

"To outsmart a hacker, you need to think like one."

This is the core of offensive security. It involves breaking into computer systems, exploiting software bugs, and finding loopholes in applications to gain unauthorized access. The goal is to understand hacker tactics and enhance our system defenses.

  • Offensive Security — The process where you simulate a hacker's actions to find vulnerabilities in a system.
  • Defensive Security — The counterpart: investigating, monitoring, and responding to attacks.
Key Takeaway

Offensive security is about finding and exploiting weaknesses before real attackers do. It's ethical because it's done with permission, in a legal and safe environment, to improve security.

02 — Hands-On

Hacking Your First Machine

TryHackMe uses Virtual Machines (VMs) — simulated environments that serve as practical complements to lessons. In this room, you hack a fake bank application called FakeBank.

The Scenario

Most companies have admin portal pages giving staff access to basic admin controls (transfer money, manage client accounts). Due to human error or negligence, these pages are sometimes not made private, allowing attackers to find hidden pages that give access to admin controls or sensitive data.

Step 1 — Open a Terminal

A terminal (command line) lets you interact with a computer without using a graphical user interface. You'll use it to run GoBuster.

Step 2 — Use GoBuster to Find Hidden Pages

GoBuster is a command-line application used to brute-force a website — it takes a list of potential page/directory names and tries accessing the website with each of them. If the page exists, it tells you.

The command used:

  • gobuster -u http://fakebank.thm -w wordlist.txt dir
  • -u — The target website URL to scan.
  • -w — A wordlist: a text file containing a list of words to try as page names.
  • dir — Directory/file brute-forcing mode.

GoBuster scans the website with each word in the list and reports results with HTTP status codes:

  • Status 200 — Page found and accessible.
  • Status 301 — Page found but redirects somewhere else.

Results found:

  • /images (Status 301)
  • /bank-transfer (Status 200) — this is the interesting one.

Step 3 — Hack the Bank

The hidden page /bank-transfer is a secret page that allows transferring money between bank accounts. An attacker with this access could steal money from any account. As an ethical hacker, you find this vulnerability and report it to the bank so they fix it before a real attacker exploits it.

Key Takeaway

A hidden page is not a secure page. If it exists on the server, it can be found through brute-forcing. This is called security through obscurity — and it doesn't work. Real security requires proper access controls (authentication, authorization).

03 — Career Paths

Careers in Cyber Security

The advice: break it down, pick an area you're interested in, and practice regularly with hands-on exercises. Build a habit of learning a little bit each day.

Offensive Security Roles

Penetration Tester
Responsible for testing technology products for finding exploitable security vulnerabilities.
Red Teamer
Plays the role of an adversary, attacking an organization and providing feedback from an enemy's perspective.
Security Engineer
Designs, monitors, and maintains security controls, networks, and systems to help prevent cyberattacks.

How to Start

  • Pick an area of cybersecurity you're interested in.
  • Practice regularly with hands-on exercises (TryHackMe, HackTheBox…).
  • Build a habit — a little bit every day adds up fast.
  • People come from all backgrounds (construction workers, music teachers, students). There's no single path in.
Key Takeaway

Consistency beats intensity. Practicing a little bit every day is more effective than cramming. The most important thing is to start and keep going.

Vocabulary

Key Terms

  • Offensive Security — Simulating a hacker's actions to find vulnerabilities before attackers do.
  • Ethical Hacking — Hacking with permission to improve security, not to cause harm.
  • Red Team — The offensive team simulating real attacks on an organization.
  • Blue Team — The defensive team detecting and responding to attacks.
  • Penetration Testing — Authorized testing of systems for exploitable vulnerabilities.
  • GoBuster — Command-line tool for brute-forcing website directories to discover hidden pages.
  • Brute-Forcing — Trying many possibilities systematically until one works.
  • Wordlist — A text file containing potential names to try during brute-forcing.
  • HTTP Status 200 — Page found and accessible.
  • HTTP Status 301 — Page found but redirects.
  • Security through Obscurity — Relying on hiding something instead of properly securing it (bad practice).
  • Virtual Machine (VM) — A simulated computer environment used for safe, practical exercises.
